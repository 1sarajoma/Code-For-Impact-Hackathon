All About Scam Centers

An interactive educational Python application built with Tkinter, ttkbootstrap, and Turtle graphics.
This project is designed to teach people about the dangers of scam call centers, how they operate, and how to protect themselves.

🎯 Purpose

Raise awareness about scam call centers.

Provide an interactive quiz to test your knowledge.

Allow users to draw with Turtle graphics for fun and engagement.

Display educational information with images and text.

🖥️ Features
1. Main Window

Scrollable interface with images and descriptions explaining scam call centers.

Educational facts, examples, and prevention tips.

2. Interactive Quiz

Multiple-choice quiz using questions, answers, and choices from information_quiz.py.

Tracks:

✅ Correct answers

❌ Wrong answers

❓ Unanswered questions

Displays:

Score counter

Progress bar

Status indicators (✓, ✗, ?) for each question

Navigation buttons: Previous and Next.

Shows final score when completed.

3. Turtle Graphics Window

A separate drawing canvas where you can:

Move the turtle with arrow keys.

Change pen color.

Adjust line thickness with a slider.

Draw clouds, sun, and your own designs.

Comes with instructions panel for controls.

4. Navigation Buttons

Start Quiz – Opens the quiz window.

Turtle Graphics – Opens the turtle drawing tool.

Quit – Exits the program.

🕹️ Controls
Quiz

Click on one of the 4 multiple-choice buttons.

Use Next / Previous to navigate questions.

Turtle Graphics

Up Arrow → Move forward and draw

Down Arrow → Move forward without drawing

Left Arrow → Turn left 15°

Right Arrow → Turn right 15°

Color Buttons → Change pen color

Slider → Adjust pen thickness

⚙️ Installation

Install Python 3.8+

Install required packages:

pip install tkinter ttkbootstrap


(Tkinter comes preinstalled with Python, but ttkbootstrap must be installed separately.)

Make sure the following files are in the same folder:

main.py

information_quiz.py

Scampic1.png … Scampic10.png

Run the application:

python main.py

📝 Notes

The quiz questions/answers are stored separately in information_quiz.py.

You can easily add more questions by editing that file.

The turtle window is just for creativity – draw your own “scam call center” or designs!

The main content is scrollable, so all 10 scam awareness images and facts are easy to browse.

🎓 Educational Value

This project helps people learn:

How scam call centers operate.

Why they target vulnerable groups.

Ways to protect yourself from phone scams.

Real-world prevention measures.
